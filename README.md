# Искра

**Твоя переписка в Телеграме — это список людей, которых ты забыл.** Искра поднимает
его обратно и превращает в то, чем можно меняться с другими фаундерами.

Перед огнём всегда есть искра — короткое соединение между двумя. Одно тело искры
не высекает, поэтому здесь всё про обмен.

## Что она делает

Два шага, и оба идут на твоём компьютере.

**1. Кто у меня есть.** Читает личные диалоги и собирает список: компания, роль,
решает ли человек сам, о каких задачах вы говорили и — главное — при каких условиях
он выйдет на встречу. Четыре ступени:

- придёт по просьбе — позвал, и он пришёл;
- придёт под смысл — сначала спросит, что будет на встрече;
- предметный диалог — встреч не было, но говорили по делу;
- только отклик — ответил, и всё.

На выходе два файла: **полный остаётся у тебя**, обезличенный — без имён, ников
и контактов — тот, которым ты меняешься.

**2. Мои запросы.** Читает твои собственные сообщения и поднимает, кого ты искал
и по какому поводу. Спроси фаундера, кто ему нужен, — услышишь «клиенты». А в переписке
за два года это записано точно: он сам просил одно и то же десятки раз, разными словами.
Плюс поле «чем могу отблагодарить» — без него это не обмен, а просьба.

## Зачем это вдвоём

Ты отдаёшь обезличенный список и свой слепок запросов. Другой фаундер — свой.
Каждый проходит по чужому и отмечает: вот эти мне интересны, а вот этих я дам тебе.
Имена открываются последними и только по совпадениям.

Дальше арифметика: вдвоём находится немного, вдесятером — на порядок больше,
потому что пары растут перемножением, а не сложением. Поэтому Искра сама предложит
собрать фокус-группу и поставить себе цель — пятьдесят новых соединений за квартал.

## Как поставить

```
pip3 install telethon
```

Ключи своего аккаунта — на **my.telegram.org** → API development tools. Положить рядом
со скриптом в файл `.env`:

```
TG_API_ID=1234567
TG_API_HASH=ваш_хеш
```

Выгрузить переписку:

```
python3 vygruzka_tg.py --dney 365 --min-soobscheniy 5
```

Дальше открываешь папку в Claude Code (или любом помощнике, который читает файлы)
и говоришь: «разбери мою телегу по скилу Искры». Скилы лежат в `skily/`.

## Что с приватностью

- Выгрузка, имена и контакты остаются на твоём компьютере. Наружу не уходит ничего,
  скрипт умеет только читать Телеграм — ни одного сетевого вызова больше.
- Наружу ты отдаёшь **один файл, который сам посмотрел**: без имён, ников, телефонов,
  почт и ссылок.
- `.session` — это доступ к твоему аккаунту. Не копируй его и не пересылай.
- `.gitignore` в комплекте закрывает ключи, файл входа и саму выгрузку,
  если положишь папку в репозиторий.
- Чужой список, который тебе отдали, — чужой. Не пересылай его дальше без разрешения.

## Проверка, что сработало

Не по объёму файла, а по трём числам:

1. сколько людей в списке;
2. сколько из них на первых двух ступенях тёплости;
3. **сколько ты сам бы не вспомнил** — ради этого всё и делается.

И контрольный: прошла неделя, список есть, а ты никому не написал — значит не сработало.
Архив переписки сам по себе не результат.
